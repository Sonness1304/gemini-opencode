# Changelog

## 0.1.0 — October 27, 2026

### Published

- Exported the pinned Gemini Web2API Go integration from J.A.R.V.I.S Agents.
- Included account binding, Argon action bridge, context preflight, queue, and Windows launcher references.
- Added a standalone offline Node test command and optional Windows fixture tests.
- Preserved source hashes, upstream pin, and third-party MIT notice.

### Presentation update

- Rewrote authored documentation and user-facing launcher messages in English.
- Added project overview, architecture, troubleshooting/FAQ, contribution and security guidance.
- Added issue/PR templates and a pinned GitHub Actions test workflow.
- Applied the MIT License with the owner's authorization.

### Known limitations

- Runtime development was cancelled on October 26, 2026.
- High-only multi-tool reliability, automatic session recovery, and full media support remain unaccepted or unverified.
- No prebuilt executable, account database, credentials, or chat history is included.
